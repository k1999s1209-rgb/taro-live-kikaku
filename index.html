かえれま10

人気メニューTOP10、全部当てるまで帰れません。

日程：8/5（水）20:00開始【確定・7/21】 場所：マクドナルド【8/1変更】 尺：約2時間（20:00〜22:00ごろ）生配信（店舗に着いてからスタート）
まずこれだけ

本番は 8/5（水）20:00〜。夜を空けておいてください

会場が変わりました（8/1）。はま寿司は撮影許可が下りなかったため、マクドナルドで実施します。日程・時間（8/5 20:00〜）は変わりません。

企画概要

  • たろ＆ひろまるさんが店舗でメニューを注文。人気TOP10に入っていれば ○、外れたら ×
  • 対象は全メニュー（バーガー・サイド・デザート・ドリンク全部）
  • TOP10を全て引き当てたらクリア＝帰れる。ハズレでも必ず完食・完飲
  • 答えを知っているのはむらさこさんだけ。挑戦する2人も視聴者も知らない → ネタバレなしで、視聴者もコメントで一緒に予想できる

役割分担

挑戦者
たろ
注文・完食・配信の進行
挑戦者
ひろまるさん
たろと対等なメイン演者として出演し、2人の会話で進行。注文・完食・カメラとコメント拾いを分担（画角も2人が等しく映る形が基本）
出題・判定人
むらさこさん
答え（TOP10リスト）を一人だけ持ち、注文ごとに○×を判定。当日参加が基本（来られない日は全てコメント上でOK）

ルール（ゲームの流れ）

  1. 注文は5品ずつまとめて宣言する（5品を1セット。毎回1品ずつだとお店の負担になるため）
  2. むらさこさんが配信のコメント欄に ○ か × だけ書き込む（品名のヒントは無し）。正解のときの「何位か」は言葉（声）で発表（来られない日はコメントで）。「現在3/10」のような進捗もコメントで都度共有
  3. ハズレも必ず食べ切る／飲み切ってから次の5品へ（2人で分けるのはOK・上限30品=最大6セット）
  4. TOP10全部当てたらクリア＝帰れる
  5. 制限時間90分 or 注文30品で終了 → 正解TOP10を発表して答え合わせ
    罰ゲームは無し。答え合わせが締めの山場

視聴者参加ギフト（7/21確定・ギフト指定制）

投げるギフトの種類で「できること」が変わります。各ヒントは1配信につき2回まで。出すのはむらさこさん（判定と同じコメント欄で）。

  1. 帽子と口髭ネタリクエスト権「このネタを食べてほしい」→ 2人は次の5品セットに必ず入れて食べる（どんなメニューでもOK）
  2. マネーガンジャンルヒント（「未正解ににぎり系が△品ある」）
  3. 大好き4択ヒント（「この4品のうち1つだけがTOP10入り」）
  4. 銀河5:5ヒント（4択ヒントで出た4品をさらに絞る。4択の後にだけ使える強力ヒント）

さらに、ハズレが5連続したら配信から「お楽しみ袋」（コイン山分け・対象はハートミーLv3以上）を投げるお詫びイベントあり。

お二人へのお願い

むらさこさん

  1. ネットの人気ランキングサイトを1つ選び、そのTOP10を正解リストにする（全メニュー型で。どのサイトかは答え合わせまで秘密）
  2. 配信中はコメント欄で「○」「×」だけ書き込む（正解の順位は言葉（声）で発表・来られない日はコメントで。見やすいようモデレーター登録します）
  3. 「現在3/10」のような今の状況をコメントで都度伝える（ピン留めで常時表示・途中参加の人がすぐ分かるように）
  4. ヒント文面は事前にすり合わせ
  5. 答えは配信終了まで誰にも漏らさない（この企画の生命線）

ひろまるさん

  1. 8/5（水）夜20:00〜22:00ごろの予定確保（上の「まずこれだけ」）
  2. 当日の分担相談：完食のシェア、カメラ・コメント拾い
  3. 当日は空腹で来る（ハズレが続くと満腹地獄です）

予算

総予算は約2万円（飲食4,500〜7,500円＋お楽しみ袋の原資＋機材・予備など込み）。費用の分担は別途相談。

カラオケ5番勝負

精密採点Aiで5本先取。点差が開くほど、罰が重い。

日程：8/15（土）1:00〜4:00 場所：カラオケ店（店舗選定中） 尺：約3時間 生配信
まずこれだけ

ひろまるさん、8/15（土）深夜1:00〜4:00 の都合を教えてください

店舗（精密採点Aiが使えるカラオケ店）はたろが選定中。深夜帯なのでオールナイト営業の店から選びます。罰ゲームと妨害ギフトは7/21に確定しました（下記）。

企画概要

  • たろ vs ひろまるが1曲ずつ歌い、DAM精密採点Aiの点数（小数第3位まで）で勝負。先に5勝した方が総合勝者（5-0の最短5ラウンド〜4-4からの最長9ラウンド。消化試合ゼロで、もつれるほど1曲がマッチポイントになる）
  • ラウンドごとに敗者は罰を即実行——しかも点差が開くほど罰が重くなる3段階制。総合敗者には最後にデカ罰
  • 視聴者はギフトで妨害・応援・お題決定ができ、点数ピッタリ予想が当たると賞金（コメントだけで参加無料）
  • ※歌うま配信ではありません。素人2人がAI採点に裁かれる配信です——点数がバラつくほど予想も罰も盛り上がります

ルール（1ラウンド約20分の流れ）

  1. お題決め：ジャンルをお題ルーレットで決定。「大好き」ギフトを最初に投げた人がいれば、その人がジャンルを指定できる
  2. たろ歌唱 → ひろまる歌唱（点数のピッタリ予想はGoogleフォームで随時受付・各歌唱の歌い出しで締切）
  3. 結果発表：勝敗＋点差（＝罰の重さ）が一気に決まる、1番の山場
  4. 敗者は点差レベルの罰（下の表）を即実行
  5. ラウンドの締めにピッタリ賞の当選者発表 → 次のラウンドへ
  6. 先に5勝で決着 → 総合敗者にデカ罰：激辛のものを食べる【7/21更新】

星取表は常時掲示（途中参加でも「いま3-2で王手」が一目で分かる）。曲の使い回しは禁止。長引いたら6ラウンド目以降はワンハーフ歌唱に切替、早く決着したら視聴者リクエスト歌唱のエキシビションで締めます。

点差＝罰の重さ（3段階）

点差レベル罰（7/21確定）
4点未満僅差 → 軽罰混ぜドリンク
4点〜8点中罰ゴムパッチン
8点以上大差 → 激罰ハリセンケツバット

点数が読み上げられる瞬間に「激罰キター！」まで決まる仕組み。閾値は初回の実測点差でチューニングします。

罰メニュー（7/21再改定・レベル別固定）

  1. 軽罰混ぜドリンク（ドリンクバーで数種を混ぜた一杯を飲み干す）
  2. 中罰ゴムパッチン
  3. 激罰ハリセンケツバット

くじ方式はやめてレベル別の固定罰に。総合敗者のデカ罰は「激辛のものを食べる」。

視聴者参加の4本柱

1. お題（ジャンル）決定＝ルーレット基本＋大好き（500コイン）で指定権【7/21確定】

各ラウンド冒頭、ジャンルはお題ルーレットで決定（90年代・アニソン・夏うた等のテーマ指定が基本）。「大好き」ギフトを最初に投げた人がいれば、その人がジャンルを指定できる。

2. 妨害ギフト【7/21確定・6種】

ギフトごとに妨害カード発動。どちらを妨害するかは視聴者が指定。1曲につき最大2回まで＝点数勝負は壊さない。

  1. ハンドハートキー変更（100コイン）
  2. ハンドポーズマイク割り込み3秒（100コイン）
  3. マネーガンハリセン
  4. コーギーピコピコハンマー
  5. ドーナツチキン
  6. 折り鶴倍速10秒

3. 応援加点ギフト

各歌唱直前の「応援タイム30秒」のギフト量に応じて +0.2〜最大+1.0点を加点。僅差はひっくり返るが、大差は覆らない上限設定。

4. ピッタリ賞（点数予想で賞金・参加無料）

歌唱前に「86.534」形式の点数フル予想をGoogleフォームで送信（歌い出しで締切・1人1回・送信時刻の早い方が先着）。参加は完全無料、各賞先着1名。当選者の発表は各ラウンドの締め（罰ゲームのあと）。

下4桁一致◯6.5343,000
完全一致86.5345,000

報酬の受け渡し方法（現金・ギフト券・コイン還元など）と当たりレベルとの対応は調整中。1配信の報酬総額は上限3万円（到達したらその回は終了）。

  4. お店の配信許可の条件に必ず従う
  5. 入店後の音量リハを必ずやる（マイクとミュージックのバランス）

どんな企画？

  • 福岡県を72エリア（北九州市7区＋福岡市7区＋58市町村）に分け、1エリアずつ訪ねて全制覇を目指す長期シリーズ
  • その町で頑張っている若者・お店・企業を応援し、地元グルメと町の魅力を紹介する
  • 締めのくじで次に行く町が決まる（エリア番号を視聴者がランダムに選ぶ）→ 出た町のおすすめをその場で聞く
  • 地域を盛り上げることは、たろの起業テーマ（地域再興）そのもの。本気でやる企画

目的（5つ）

  1. その町で頑張っている若者・店舗・企業の応援
  2. 地元のグルメ紹介
  3. 地元の魅力紹介
  4. 紹介を通じた企業とのタイアップなど、仕事への連携（ひろまるさん・たろの仕事につながる）
  5. シリーズ化による視聴者数の増加

ルール（5つ）

  1. 最低限の下調べをして行く
  2. 一度行った地域には行かない（全エリアを回るため）
  3. ギフトは「移動費・現地の食費・応援に使う資金」として、使い道を公表して扱う
  4. 動画の最後に、次に行く町をくじ（エリア番号）で視聴者にランダムに選んでもらい、出た町のおすすめを聞く
  5. 視聴者はスポンサーではなく協力者・参加者という位置付け

エリアの分け方（全72）

  • 1〜7：北九州市の7区（門司・小倉北・小倉南・若松・八幡東・八幡西・戸畑）
  • 8〜14：福岡市の7区（東・博多・中央・南・西・城南・早良）
